# Gestor de Tareas

Proyecto desarrollado en Python para la asignatura
Construcción de Software.

## Funcionalidades

- Registrar tareas.
- Listar tareas.
- Marcar tareas como completadas.
- Buscar tareas.
- Validar los datos ingresados por el usuario.

## Tecnologías

- Python 3.x
- Git
- GitHub
- Visual Studio Code

## Ejecución

Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

```bash
python main.py
